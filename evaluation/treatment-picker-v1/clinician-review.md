# Эмчийн хяналтын хуудас — эмчилгээний эхийн санал

Зөвхөн зохиомол хөгжүүлэлтийн тохиолдлууд. Эмчийн хариулт, цаг хэмнэлт хараахан бүртгээгүй. Шинэ narrow task; medfacts/A-v2 оноотой шууд харьцуулахгүй.

Модель: `soum-qwen3-4b-control:mlx128-52a5ab34`; prompt/contract: `treatment-picker-1`. Нийт 3 хүсэлт, нэг оролдлого. UI нь бүтэн эх ба саналын өмнөх/дараах хэсгийг тусад нь харуулна; зөвхөн хүлээн авсан хэсгийг хүүрнэлд оруулна.
